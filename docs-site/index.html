Quick Start Guide

Managing Assets

Register and organize your digital assets

CLIENT

What are Assets?

Assets represent your digital properties that can be tested. These include:

Web Applications

Websites, web apps, customer portals

Mobile Apps

iOS and Android applications

APIs

REST, GraphQL, SOAP endpoints

Infrastructure

Networks, servers, cloud resources

Adding an Asset

  1. Navigate to Assets in the sidebar
  2. Click "Add Asset" button
  3. Fill in the required information:
    • Name - Descriptive name for the asset
    • Type - Web App, Mobile, API, Network, Cloud
    • URL/Identifier - The asset location or identifier
    • Environment - Production, Staging, Development
    • Risk Level - Critical, High, Medium, Low
    • Description - Additional context about the asset
  4. Click "Create Asset"

Understanding Findings

Findings are security vulnerabilities discovered during penetration testing. Each finding includes:

  • Title - Brief description of the vulnerability
  • Severity - Critical, High, Medium, Low, or Informational
  • Status - New, Triaged, In Progress, Resolved, Closed
  • Description - Detailed explanation of the issue
  • Steps to Reproduce - How to verify the vulnerability
  • Impact - Potential business/security impact
  • Remediation - Recommended fix
  • References - CWE, CVE, OWASP references

Severity Levels

Creating Users

  1. Navigate to Users in the sidebar
  2. Click "Add User"
  3. Fill in user details:
    • Email - User's email address
    • Name - Full name
    • Password - Initial password
    • Role - Client, Pentester, or Admin
    • Company - Organization name (for clients)
  4. Click "Create User"

User Actions

  • Enable/Disable - Toggle user account status
  • Delete - Permanently remove user account
Security Note

Disabled users cannot log in but their data is preserved. Use delete only when you want to permanently remove all user data.
