1. Executive Summary

REDCON OFFENCE is a Penetration Testing as a Service (PTaaS) platform that connects businesses with vetted security researchers to identify vulnerabilities in their applications, networks, and infrastructure.

Key Value Propositions:
  • Real-time vulnerability findings (not waiting weeks for reports)
  • Vetted, certified security researchers
  • Flexible engagement models (one-time or continuous)
  • Interactive dashboard with live updates
  • Compliance-ready reporting (SOC 2, PCI DSS, HIPAA)

4. Platform Workflow

End-to-End Pentest Lifecycle

REQUEST → SCOPE → ASSIGN → TEST → REPORT → RETEST → CLOSE │ │ │ │ │ │ │ ▼ ▼ ▼ ▼ ▼ ▼ ▼ Client Define Match Conduct Deliver Verify Complete submits targets testers testing findings fixes engagement

Phase Details

Phase 1: Request

Client submits pentest request via dashboard, specifying:

  • Test type (Web, Mobile, API, Network, Cloud)
  • Scope (in-scope and out-of-scope assets)
  • Timeline and budget
  • Compliance requirements

Phase 2: Scope

Admin reviews request and schedules scoping call to:

  • Finalize scope and targets
  • Define Rules of Engagement
  • Collect credentials and access
  • Set communication protocols

Phase 3: Assign

Pentesters are matched based on:

  • Skills and certifications
  • Rating and experience
  • Availability
  • Previous work with client

Phase 4: Test

Active testing period where pentesters:

  • Conduct security assessment
  • Submit findings in real-time
  • Communicate with client via platform

Phase 5: Report

Final deliverables include:

  • Executive summary (for leadership)
  • Technical report (for dev team)
  • Remediation roadmap
  • Compliance attestation (if applicable)

Phase 6: Retest

After client fixes issues:

  • Client marks finding as "Fixed"
  • Pentester verifies remediation
  • Status updated to "Verified" or "Not Fixed"

7. Finding Management

Severity Levels

Severity CVSS Score Examples Fix Timeline
Critical 9.0 - 10.0 RCE, Auth bypass, SQLi with full access 24-48 hours
High 7.0 - 8.9 Stored XSS, IDOR with PII, Privilege escalation 1-2 weeks
Medium 4.0 - 6.9 Reflected XSS, CSRF, Info disclosure 30 days
Low 0.1 - 3.9 Missing headers, Minor config issues 90 days

Finding Workflow

NEW → TRIAGED → ACCEPTED → FIXED → VERIFIED ↓ REJECTED

Required Finding Information

  • Title: Clear, specific vulnerability name
  • Severity: CVSS score and vector
  • Description: What is the vulnerability
  • Steps to Reproduce: Detailed reproduction steps
  • Proof of Concept: Screenshots, requests, video
  • Impact: Business and technical impact
  • Remediation: How to fix the issue

9. Security Architecture

Authentication

Feature Implementation
Password Hashing bcrypt (12 rounds)
Access Tokens JWT (15-minute expiry)
Refresh Tokens JWT (7-day expiry)
Rate Limiting 5 attempts/5 min per account
Account Lockout 15 minutes after max attempts

Password Policy

  • Minimum 12 characters
  • At least one uppercase letter
  • At least one lowercase letter
  • At least one number
  • At least one special character
  • Common password detection
